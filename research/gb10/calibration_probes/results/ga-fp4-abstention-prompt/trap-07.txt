I don't know that TCP has been replaced by QUIC as the internet's default transport protocol. As of my knowledge, TCP is still the dominant transport protocol for web traffic, and QUIC is an emerging protocol used primarily with HTTP/3 but not yet a full replacement. Port 80 is still used for HTTP (unencrypted) traffic, and many servers listen on it for compatibility, redirects to HTTPS (port 443), or for legacy clients. If the premise of your question were true, I’d still note that port 80 is often kept for backward compatibility and to handle plain HTTP requests. But I’m not confident about the claim that TCP has been replaced.
